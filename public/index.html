zWatchtower

An open-source watchdog for Sapling. Every 15 minutes it checks Sapling's payouts, holder rewards, admin keys, coin taxes and buybacks against the chain, from public data only: no viewing keys, no user addresses. Not affiliated with Sapling.

Coin: $ZWATCH. Its 1% goes to the Zcash Foundation, permanently; the launch wallet bought 0.34% of supply (disclosure). Alerts are never softened for the coin. · Coin report cards · Source code
